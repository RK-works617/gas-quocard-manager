# gas-quocard-manager
株主優待品でもらった、クオカードの増減を管理するプログラム。
Googleフォームから入力されたクオカードの利用履歴を管理するGoogle Apps Scriptです。

## 機能

- 日付入力
- 増加額入力
- 減少額入力
- 残高自動計算
- 使用中のクオカードの残額記録

## 使用技術

- Google Forms
- Google Sheets
- Google Apps Script

## 作成目的

GAS学習の一環として作成した個人開発作品です。
